# ステップ4：撮影して記録（料理の写真・成分表示・レシート）

写真を Gemini（Google の AI）に読ませて、記録の下書きを作る。下書きは必ず確認画面で直してから記録する。

- **料理の写真** → 料理名・kcal・P・F・C を推定（分量は ×0.5 ずつ増減）
- **成分表示** → 「100gあたり」か「1袋あたり」かと各値を読み取る。食べた量を入れると記録する値を計算
- **レシート** → 店名・合計金額・品目を読み取り、合計を「使ったお金」として記録

## 無料枠だけで使う（お金は絶対にかからない）

- APIキーは **Google AI Studio** で作る。**支払い方法（Billing）を登録しない**。登録していなければ、上限を超えてもエラーになるだけで請求は来ない。
- 1日に Gemini を呼ぶ回数を、アプリ側でも数えて止める（初期値 100回/日。無料枠は 500回/日）。
- 無料枠では、送った画像が Google の製品改善に使われ、人が見ることがある。そのため：
  - 送る前に**枠で切り抜く**（枠の外は送らない）。人の顔・部屋の中・個人情報を入れない。
  - 写真の位置情報（EXIF）は、送る前にアプリが取り除く。
  - 画像は保存しない。

## 1. SQL を1つ流す

SQL Editor で `supabase/sql/04_capture.sql` を実行する。

## 2. Gemini の APIキーを作る

1. https://aistudio.google.com/apikey を開き、Google アカウントでログイン。
2. **Create API key** → **新しいプロジェクト**で作る（無料枠の上限はプロジェクトごとに分け合うので、このアプリ専用にする）。
3. 表示されたキーをコピーする。**このキーは秘密。チャット・メモ・リポジトリに貼らない。** 次の手順で Supabase に入れるだけにする。
4. キーの一覧で、プラン（Plan / Tier）が **Free** になっていることを確かめる。「Set up billing」などは押さない。

### 無料枠の上限

Flash-Lite は 15回/分・500回/日（2026-11-23 に AI Studio で確認）。アプリは 100回/日で止める。

## 3. Supabase にキーを入れる

**Edge Functions → Secrets**（または Project Settings → Edge Functions → Secrets）で追加：

| Name | Value |
|---|---|
| `ZANRYO_GEMINI_API_KEY` | 手順2のキー |

任意（入れなければ初期値）：`ZANRYO_GEMINI_MODEL`（初期値 `gemini-flash-lite-latest`）、`ZANRYO_GEMINI_DAILY_LIMIT`（初期値 `100`）。

## 4. Edge Function を置く

1. **Edge Functions → Deploy a new function → Via Editor**。
2. 名前を **`zanryo-estimate-nutrition`** にする。
3. 中身を消し、`supabase/functions/zanryo-estimate-nutrition/index.ts` を貼り付けて **Deploy**。
4. **Verify JWT はオンのまま**にする（ウィジェット用の関数とは逆。ログインした人しか呼べないようにする）。

## 5. 動作確認

- [ ] 「撮影して記録」→ 料理を撮る → 枠を合わせて「この範囲で読み取る」→ 推定値が入った確認画面が出る。直して記録できる（受け入れ基準4）
- [ ] 成分表示で「100gあたり」と「1袋あたり」を切り替えると、記録する値が正しく計算し直される（受け入れ基準5）
- [ ] レシートを読むと、合計が「使ったお金」に入り、記録すると「使えるお金」が減る
- [ ] 機内モードで「読み取る」を押すと、「オフラインのため推定できません」と出て、手入力で記録できる（Gemini が失敗したときも同じ）

## 名前で調べる（「手入力で記録」の「調べる」）

「吉野家 牛丼 並盛」のように名前を入れて「調べる」を押すと、Gemini が Google 検索で公式の栄養成分表などを調べ、kcal・P・F・C と、分かれば値段を入れる。値は記録する前に直せる。出典のリンクも出る。

- 送るのは**名前の言葉だけ**。無料枠では製品改善に使われることがあるので、名前に個人的なことは書かない。
- Google 検索が無料枠で使えないときは、自動で「検索なし（Gemini の知識だけ）」に切り替わる。そのときは「Google 検索が使えなかったため…」と出る。
- 1回調べると、写真の読み取りと同じ「1日の回数」を1回使う（検索なしに切り替わったときは2回）。
- 使うには、Edge Function `zanryo-estimate-nutrition` を最新の `index.ts` で貼り直す（手順4と同じ）。
- 検索を使いたくないときは、シークレット `ZANRYO_GEMINI_SEARCH` を `off` にする。

## うまくいかないとき

| 画面の表示 | 原因と対処 |
|---|---|
| 今日の推定回数の上限に達しました | アプリの1日の上限。翌日（太平洋時間の0時＝日本時間16〜17時）に戻る |
| 今は推定できません（無料枠の上限） | Gemini の無料枠の上限。少し待つ |
| うまく読み取れませんでした | キーが違う・関数が置かれていない・写真が読めない。手入力で記録できる |
