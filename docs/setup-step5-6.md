# ステップ5・6：過去の日・記録漏れのお知らせ・設定

新しく流す SQL や、Supabase の設定はない。アプリを開き直せば使える。
画面の位置は v1 の形（下のタブ）で書いている。

## ステップ5：過去の日（§3.5, §5.3）

- **日付を移動する**：画面の下の「‹ 日付 ▾ ›」。日付をタップすると日付を選べる。過去の日では「今日」ボタンで戻れる。ホーム・記録一覧は左右のスワイプでも移動できる。
  - 選べるのは今日を含めて直近31日。未来の日には進めない。
- **過去の日の画面**：見出しが青い「11/21（土）の記録」になり、「＋で記録すると11/21（土）に入ります」と出る。
  - プリセット・撮影・手入力で記録したものは、すべてその日に入る。今日の残量は変わらない。
  - 記録を直す・削除することもできる。
- **記録漏れのお知らせ**：直近7日（今日を除く）に記録していない日があると、今日の画面の一番上にオレンジのお知らせが出る。
  - 1日なら「11/21（土）の記録がありません」、2日以上なら「記録していない日が2日あります」。
  - タップすると、記録していない日のうち一番古い日を開く。記録一覧の画面に、ほかの記録していない日へのリンクも出る。
  - 閉じるボタンはない。その日に記録するか、「記録なしで確定」すると消える。
- **この日は記録なしで確定**：記録が0件の過去の日に、画面の下に出る。何も食べず、お金も使わなかった日として確定する（DB の今月の節約の集計では、その日の目標額がそのまま足される）。確定は取り消せる。

## ステップ6：設定（§5.4）

下のタブの「設定」から開く。

- **ターゲット**：目標値・名前・種類（上限／到達）を直す、追加する、↑↓で並べ替える、「使う」を外して表示しないようにする。
  - v1 以降：目標の期間（1日・1週間・1か月）。v1.1 以降：休日の目標（[setup-v1.md](setup-v1.md)）。
  - 目標を変えると今日から反映され、過去の日の目標は変わらない。
  - カロリー・P・F・C・お金は、写真の読み取りや節約の計算で使うので、単位は変えられない。削除はできない（使わない設定にする）。
- **プリセット**：名前と量を直す、↑↓で並べ替える、削除する（これまでの記録は消えない）。
  - ＋のシートには、すべてのプリセットがよく使う順に並ぶ（9つ以上あると「プリセットを探す」欄が出る）。設定の並び順は設定の画面での並び。
- **ウィジェット**：トークンの発行・再発行・無効化。新しいトークンは**その場で1回だけ**表示される（端末にも保存しない）。「トークンをコピー」して Scriptable の「URLとトークンを設定」に貼る。再発行すると古いトークンは使えなくなる。
- **写真の読み取り**：今日の読み取り回数。
- **アカウント**：パスワードを決める・変える、ログアウト（この端末に残した記録のコピーと、未送信の記録を消してからログアウトする）。
- **このアプリについて**：版（コミット）と作った日時。iPhone に新しい版が入ったかをここで確かめる。

## 動作確認

- [ ] 直近7日に記録していない日があると、今日の画面にお知らせが出る（受け入れ基準8）
- [ ] お知らせをタップすると、その日の画面が開く。記録するか「記録なしで確定」すると、お知らせからその日が消える（受け入れ基準8）
- [ ] 過去の日に記録すると、その日の残量が変わり、今日の残量は変わらない（受け入れ基準9。節約は DB のテストで確かめる）
- [ ] 日付をタップして日付を選べる。次の日は今日より先に進めない
- [ ] 設定で目標を変えると今日の画面に反映され、昨日の画面の目標は変わらない
- [ ] 設定でトークンを発行し、Scriptable に入れ直すとウィジェットに残量が出る

## スクリーンタイムを記録する（自分で追加するターゲットの例）

iPhone のスクリーンタイムの数字は、Apple の仕組み上、このアプリから直接は読めない。1日1回、数字を入れる。

1. **設定 → ターゲット → ＋ ターゲットを追加**
   - 名前：`スクリーンタイム`、1日の目標：`120`、単位：`分`、種類：**上限**
2. 毎朝、iPhone の **設定 → スクリーンタイム** で前日の時間を見る。
3. アプリで「‹ 前の日」→ ＋ →「手入力」→ 名前に `スクリーンタイム`、「スクリーンタイム（分）」の欄に分数（例：2時間15分なら `135`）→「記録する」。
   - 「調べる」は押さない（押すと名前の言葉が Google に送られる。調べても何も出ない）。
4. ウィジェット（任意）：円形の Parameter に `スクリーンタイム` と書くと「残り 75分」「超過 45分」と出る。中サイズのホーム画面ウィジェットにも出る。
