# v1：スクロールしない画面・下のタブ・週と月・目標の期間

見た目の正解：Design モックの「v1 案」の段（Home2 / RecordSheet / Entries / PeriodWeek / PeriodMonth / TargetEdit）。

## 1. SQL を1つ流す

SQL Editor で `supabase/sql/05_periods.sql` を実行する（1回だけ）。

- ターゲットに「目標の期間」（1日・1週間・1か月）を持たせる
- 週・月の目標のときの残量の計算、週・月の画面のための集計（`range_summary`）
- 今月の節約は、週・月の目標を1日あたりに割った額で数える

流す前でもアプリは開けるが、「期間」の画面は「05_periods.sql を流してください」と出る。

## 2. 使い方

画面の下のタブ：**ホーム ／ 記録一覧 ／ ＋（記録） ／ 期間 ／ 設定**

- **ホーム**：スクロールしない。カロリーの円とほかのターゲットの棒。下（親指の届く位置）によく使うプリセット。
  - ゲージはどの型も**満タンから減っていく**。右端は「残61%」。上限型で超えたら、黒い縦線（目標）の右にオレンジで伸びて「+13%」。到達型は 0 になったら「達成 ✓」。
  - 日付の「‹ ›」と、日付をタップして選ぶ。過去の日は「ここで記録すると〇〇に入ります」と出る。
- **記録一覧**：その日の記録。タップで直す・削除する。
- **＋**：名前で調べる・料理を撮る・成分表示・レシート・手入力・すべてのプリセット（よく使う順）。
- **期間**：週（月曜はじまり）と月。ターゲットを選んで、合計と目標・日ごとの棒（週）・カレンダー（月）・目標内／超過／未記録の日数。日付をタップするとその日を開く。
  - 合計と比べる目標は、**記録した日の分だけ**（未記録の日を入れると実際より良く見えるため）。週の目標のターゲットを週で見るときは、その週の目標。
- **設定**：ターゲットの「目標の期間」を 1日・1週間・1か月 から選べる。例：お金を「1週間 7,000円」にすると、ホームに「今週の残り」と「今日使った額」が出て、月曜の朝4:00に戻る。

## 3. 動作確認

- [ ] ホーム・記録一覧・期間は、ページ全体がスクロールしない（設定だけはスクロールする）
- [ ] プリセットを押すと棒が減り、右端の % が変わる。取り消すと戻る
- [ ] 上限を超えると、線の右にオレンジが伸びて「+〇%」。P は 0 で「達成 ✓」
- [ ] ＋ → 名前を入れて「調べる」→ 手入力の画面で値が入る
- [ ] 期間 → 週・月を切り替え、ターゲットを選べる。日付をタップするとその日のホーム
- [ ] 設定でお金を「1週間」にすると、ホームに「上限・週」「今週（〇/〇〜）· 今日 ¥〇」
