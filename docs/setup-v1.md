# v1 / v1.1：今の画面構成・週と月・目標の期間・平日と休日の目標

仕様としての要点は [CLAUDE_CODE_INSTRUCTIONS.md](CLAUDE_CODE_INSTRUCTIONS.md) の §5.5。ここは手順と使い方と確認。

見た目の正解：Design モックの「v1 案」の段（Home2 / RecordSheet / Entries / PeriodWeek / PeriodMonth / TargetEdit）。

## 1. SQL を1つ流す

SQL Editor で `supabase/sql/05_periods.sql` を実行する（1回だけ。**済み**）。

- ターゲットに「目標の期間」（1日・1週間・1か月）を持たせる
- 週・月の目標のときの残量の計算、週・月の画面のための集計（`range_summary`）
- 今月の節約は、週・月の目標を1日あたりに割った額で数える

流す前でもアプリは開けるが、「期間」の画面は「05_periods.sql を流してください」と出る。

## 2. 使い方

よく押すもの（日付の移動・項目や表示の切り替え）は、どの画面も**画面の下（タブのすぐ上）**にまとめている。上は見出しと情報だけ。

画面の下のタブ：**ホーム ／ 記録一覧 ／ ＋（記録） ／ 期間 ／ 設定**

- **ホーム**：見ることに徹する画面（記録は下の「＋」から）。スクロールしない。カロリーの円とほかのターゲットの棒。各ターゲットに「目標」と「使った（摂取）量」。
  - **左右にスワイプ**すると日付が変わる（左へ＝次の日、右へ＝前の日。今日より先には進まない）。
  - **ペースの目安（▼）**：「いまの時刻なら、残りはこのくらいが目安」の位置。1日（朝4:00〜翌朝4:00）のうち過ぎた割合で、まっすぐ減るとして計算する（週・月の目標は、週・月のうち過ぎた割合）。青い棒が▼より長ければ余裕。棒の下に「目安より 〇 余裕／使いすぎ」（上限型）、「遅れ／先行」（到達型）。差が5%以内なら「目安どおり」。今日を見ているときだけ出る。
    - 既定はカロリー・P・F・C だけ。お金やスクリーンタイムのようにまとめて入力するものは出さない。設定のターゲットの編集で「ペースの目安を出す」を切り替えられる（この端末にだけ保存）。
  - ゲージはどの型も**満タンから減っていく**。右端は「残61%」。上限型で超えたら、黒い縦線（目標）の右にオレンジで伸びて「+13%」。到達型は 0 になったら「達成 ✓」。
  - 日付は下の「‹ 日付 ›」で移動・タップして選ぶ。過去の日は「今日」ボタンで戻れる。「＋で記録すると〇〇に入ります」と出る。
- **記録一覧**：その日の記録。タップで直す・削除する。左右のスワイプで日付が変わる。
- **＋**：名前で調べる・料理を撮る・成分表示・レシート・手入力・すべてのプリセット（よく使う順。9つ以上あると「プリセットを探す」欄が出る）。
  - 撮ったあとは、送る範囲を枠で決める（四すみの丸で大きさを変える。枠の外は送らない）。詳しくは [setup-step4.md](setup-step4.md)。
- **期間**：週（月曜はじまり）と月。左右のスワイプで前後の週・月へ。目標に対してどれだけ積み上がったかはここで見る（ホームの「残り／積み上げ」の切り替えはなくした）。ターゲットを選んで、合計と目標・日ごとの棒（週）・カレンダー（月）・目標内／超過／未記録の日数。日付をタップするとその日を開く。
  - 合計と比べる目標は、**記録の有無にかかわらず期間の日数分**（週は7日分、月はその月の日数分。必ず記録する前提）。週の目標のターゲットを週で見るときは、その週の目標。1日平均は、過ぎた日数で割る（記録していない日は 0）。
  - グラフは切り替えられる：週は「棒／折れ線」、月は「カレンダー／棒／折れ線」（最後に選んだものを覚える）。
  - **折れ線**は、期間の始まり（0）からの積み上げ（青い線）が、期間の目標（横の点線）に対してどこまで来たか。縦軸に目盛り、横軸に曜日（月は日付）。曜日の文字は、その日の点（日の終わり）の真下にあり、日の区切りに薄い縦線。薄い点線は目安（「期間の終わりにちょうど目標になるペース」。日ごとの目標の積み上げなので、毎日同じ目標なら直線、休日の目標が大きければ休日で傾きが大きくなる）。点は日ごとに1つ（各日の終わりの位置。時刻では動かない）。今日の点は途中なので白抜き。点が目安の線より下なら目安より少ない。下に「今日あと 〇」（上限を超えたら「今日の目安を 〇 超えています」）。その下に小さく「今日の目安 〇（今週の残り÷残りの日） · 今日ここまで 〇」。過ぎた週・月は「目標より 〇 少ない／多い」。
- **設定**：ターゲットの「目標の期間」を 1日・1週間・1か月 から選べる（1日なら「休日の目標」も。下の v1.1）。例：お金を「1週間 7,000円」にすると、ホームに「今週の残り」と「今日使った額」が出て、月曜の朝4:00に戻る。

## 3. 動作確認

- [ ] ホーム・記録一覧・期間は、ページ全体がスクロールしない（設定だけはスクロールする）
- [ ] ホーム・記録一覧・期間で、左右にスワイプすると日付（期間）が変わる
- [ ] 今日のホームで、カロリー・P・F・C に▼と「目安より〇」が出る。お金には出ない（設定でオンにすると出る）
- [ ] ＋ → プリセットを押すと、ホームの棒が減り、右端の % が変わる。取り消すと戻る
- [ ] 上限を超えると、線の右にオレンジが伸びて「+〇%」。P は 0 で「達成 ✓」
- [ ] ＋ → 名前を入れて「調べる」→ 手入力の画面で値が入る
- [ ] 期間 → 週・月を切り替え、ターゲットを選べる。日付をタップするとその日のホーム
- [ ] 期間 → 週の目標が「7日分」、月の目標が「その月の日数分」になっている。グラフを棒・折れ線（月はカレンダーも）に切り替えられる
- [ ] 設定でお金を「1週間」にすると、ホームに「上限・週」「今週（〇/〇〜）· 今日 ¥〇」

## v1.1：平日と休日で目標を分ける

### やること（1回だけ）

1. Supabase の **SQL Editor** を開き、`supabase/sql/06_holidays.sql` の中身を全部貼り付けて **Run**（**済み**）。
   - 「Success」と出ればOK。もう一度流すと「すでに実行済みです」と出て止まる（何も変わらない）。
   - 流す前でもアプリは今までどおり動く（休日の表示が出ないだけ）。
2. アプリの **設定 → ターゲット → 使えるお金** を開き、「休日の目標」に金額を入れて保存。

### しくみ

- 休日の目標は、目標の期間が「1日」のターゲットだけ。空欄なら平日と同じ。
- 休日は、**土日と国民の祝日**（振替休日・国民の休日を含む）を自動で判定する（DB の `zanryo.jp_holiday_name`）。
- 有給・休日出勤などは、ホームの日付の右の「平日 ⇄／休日 ⇄」をタップして切り替える（直近31日まで。土日祝と同じ判定に戻すと自動に戻る）。
  このボタンは、休日の目標を入れたターゲットがあるときだけ出る。
- その日の目標は、その日のスナップショット（`day_goals`）に平日・休日の両方を残しておき、休日なら休日の目標を使う。あとで目標を変えても過去の日は変わらない。
- 期間の画面：週・月の目標は「その期間の日ごとの目標の合計」（まだ来ていない日も、その日が休日なら休日の目標で数える）。
  棒グラフは日ごとに目標の横線、折れ線の目安は日ごとの目標の積み上げ（休日で傾きが大きくなる）。休日の日付はオレンジ。

### 確かめること

- [ ] 設定の一覧に「1日 ¥1,000（休日 ¥3,000）」のように出る
- [ ] 土日・祝日のホームでお金の目標が休日の目標になり、日付の右に「休日」や祝日の名前が出る
- [ ] 平日に「平日 ⇄」をタップ → 確認 → 「休日（手動）」になり、目標が休日の目標に変わる。もう一度タップで戻る
- [ ] 期間 → お金 → 週の合計の目標が「平日の目標×平日の日数＋休日の目標×休日の日数」になっている
